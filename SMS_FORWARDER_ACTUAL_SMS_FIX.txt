ISSUE 1: ROUTING PARAMETER AY HINDI MATCH SA ACTUAL NUMBER
─────────────────────────────────────────────────────────────

✅ I-check:
   - Ang Routing Parameter sa SMS Forwarder: 09954778940
   - Ang actual number na naka-receive ng SMS: dapat 09954778940
   - Dapat EXACT match (walang space, walang dash)

✅ I-verify:
   - I-check kung ang number na naka-receive ay: 09954778940
   - Hindi dapat: +639954778940, 9954778940, o ibang format
   - Dapat may leading zero (0995... hindi 995...)

───────────────────────────────────────────────────────────────

ISSUE 2: SMS FORWARDER AY HINDI NAKA-ENABLE PARA SA INCOMING SMS
─────────────────────────────────────────────────────────────────

✅ I-check sa SMS Forwarder app:
   1. Dapat naka-ON ang "Forward Incoming SMS"
   2. Dapat naka-ON ang "Auto Forward SMS"
   3. Dapat naka-ON ang "Monitor Incoming Messages"
   4. I-check kung may "Enable SMS Forwarding" toggle

───────────────────────────────────────────────────────────────

ISSUE 3: SMS PERMISSIONS AY HINDI GRANTED
──────────────────────────────────────────

✅ I-check sa Android Settings:
   1. Settings → Apps → SMS Forwarder
   2. Permissions → Dapat naka-ON ang:
      - SMS (Read SMS)
      - Phone (Read Phone State)
      - Notifications
   3. I-check kung may "Allow SMS Access" permission

───────────────────────────────────────────────────────────────

ISSUE 4: SMS FORWARDER AY HINDI NAKA-RUN SA BACKGROUND
───────────────────────────────────────────────────────

✅ I-check:
   1. Dapat naka-ON ang "Run in Background"
   2. Dapat naka-ON ang "Battery Optimization" exemption
   3. Dapat naka-ON ang "Auto-start" o "Start on Boot"
   4. I-check kung may notification na "SMS Forwarder is running"

───────────────────────────────────────────────────────────────

ISSUE 5: NUMBER FORMAT AY HINDI MATCH
──────────────────────────────────────

✅ I-check:
   - Kung ang natanggap na SMS ay galing sa: 09123456789
   - Pero ang routing parameter ay: 09954778940
   - Dapat match ang format (may leading zero)

✅ I-test:
   - I-send ang SMS sa: 09954778940 (dapat may zero)
   - Hindi dapat: 9954778940 (walang zero)
   - Hindi dapat: +639954778940 (may country code)

───────────────────────────────────────────────────────────────

ISSUE 6: SMS FORWARDER AY HINDI NAKA-DETECT NG INCOMING SMS
────────────────────────────────────────────────────────────

✅ I-check sa SMS Forwarder app:
   1. Hanapin ang "Logs" o "History"
   2. I-check kung may entry para sa incoming SMS
   3. I-check kung may error message
   4. I-check kung na-detect ang SMS

───────────────────────────────────────────────────────────────

ISSUE 7: SIM CARD AY HINDI NAKA-INSERT O HINDI ACTIVE
──────────────────────────────────────────────────────

✅ I-check:
   - Dapat may SIM card na naka-insert
   - Dapat active ang SIM card (may signal)
   - Dapat may load o active ang plan
   - I-check kung may "No SIM" error

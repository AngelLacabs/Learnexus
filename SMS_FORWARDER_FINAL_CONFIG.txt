   Hint: "Use * symbol to catch any SMS"

2. WEBHOOK URL
   ────────────
   http://192.168.18.34/Learnexus/sms_feedback_webhook.php
   
   ⚠️  IMPORTANT: 
   - Gamitin ang HTTP (hindi HTTPS)
   - Dapat nasa parehong WiFi network ang phone at computer
   - Kung hindi same network, gamitin ang ngrok

3. JSON PAYLOAD TEMPLATE
   ──────────────────────
   {"from":"%from%","text":"%text%","sim":"%sim%"}
   
   ⚠️  EXACT format - walang extra spaces o characters

4. HEADERS
   ────────
   Header 1:
     Name:  User-Agent
     Value: SMS Forwarder App
   
   Header 2:
     Name:  Content-Type
     Value: application/json

5. ADVANCED PARAMETERS
   ────────────────────
   SIM Slot:        any
   Number Retries:  100
   Chunked Mode:    ON (checked/enabled)
   Ignore SSL/TLS certificate errors: OFF (unchecked)
